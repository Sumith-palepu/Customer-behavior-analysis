# Customer Behavior Data Analytics Project

## Overview

This project is an end-to-end Data Analytics project focused on analyzing customer behavior and generating business insights. The workflow includes data loading, exploratory data analysis (EDA), data cleaning, SQL analysis in PostgreSQL, dashboard creation in Power BI, and reporting with presentation development.

## Dataset

The dataset contains customer-related information including:

* Customer demographics
* Product categories
* Purchase details
* Subscription status
* Shipping methods
* Review ratings

## Tools & Technologies

* **Python**

  * Pandas
* **PostgreSQL**
* **Power BI**
* **Gamma**
* **Jupyter Notebook**

## Project Steps

1. Loaded dataset using Pandas
2. Performed EDA to identify trends and patterns
3. Cleaned and prepared data for analysis
4. Executed SQL queries in PostgreSQL
5. Built an interactive Power BI dashboard
6. Created reports and presentation slides using Gamma

## Dashboard

The dashboard includes:

* Total customers
* Average purchase amount
* Customer ratings
* Revenue and sales analysis
* Subscription insights
* Interactive filters and slicers

## Results

* Identified customer behavior trends
* Analyzed category-wise performance
* Compared customer segments
* Generated insights for business decision-making

## How to Run

1. Clone the repository
2. Install Pandas:

```bash
pip install pandas
```

3. Run the Python notebook
4. Execute SQL queries in PostgreSQL
5. Open the Power BI (.pbix) file and refresh the data
